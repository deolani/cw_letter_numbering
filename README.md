# CW Letter Numbering

**CW Letter Numbering** is an Odoo 17 module for automatic and configurable letter numbering.

It helps companies create consistent and structured letter numbers based on company, department, user, and configurable numbering rules.

## Features

* Automatic letter numbering
* Configurable letter types
* Company-based numbering
* Department-based numbering
* User-based numbering
* Custom numbering rules
* Custom numbering tokens
* Configurable reset periods
* Numbering history
* Centralized numbering management
* Integrated with Odoo users and employees

## Supported Odoo Version

* Odoo 17.0

## Dependencies

* Odoo `base`
* Odoo `hr`

## Installation

1. Download or clone this repository.
2. Copy the `cw_letter_numbering` folder into your Odoo custom addons directory.
3. Make sure the custom addons directory is included in your Odoo `addons_path`.
4. Restart the Odoo server.
5. Activate Developer Mode.
6. Go to **Apps**.
7. Click **Update Apps List**.
8. Search for **CW Letter Numbering**.
9. Click **Install**.

## Configuration

After installation, configure the required letter numbering settings from the **CW Letter Numbering** menu.

You can define:

* Letter types
* Numbering rules
* Numbering scope
* Reset periods
* Numbering history

## Numbering Rules

CW Letter Numbering is designed to support flexible numbering rules.

Depending on the configuration, the generated letter number can be associated with:

* Company
* Department
* User
* Letter type
* Period or sequence

## Numbering History

The module keeps numbering history so users can track previously generated letter numbers.

This helps prevent duplicate numbering and provides better control over document numbering.
